# Contributing

This project is currently in early prototype stage. Contributions should focus on clarity, safety, and working vertical slices.

## Before changing code

- Read `README.md`.
- Read `SECURITY.md`.
- Check `docs/ROADMAP.md`.
- Do not add real secrets, private media, client assets, or generated exports.

## Branch style

Use short, descriptive branch names:

- `feat/upload-flow`
- `fix/job-status`
- `docs/setup-notes`
- `chore/security-cleanup`

## Commit style

Use simple conventional-style commits:

- `feat: add upload status panel`
- `fix: handle failed render jobs`
- `docs: update setup guide`
- `chore: tighten gitignore`

## Pull request checklist

- No secrets committed.
- No private media committed.
- App still starts locally.
- README or docs updated if behavior changed.
- Security impact considered.
